Chào mừng đến với khu vực dự án đồng sáng tạo Hello-Agents! Đây là nơi người học trưng bày ứng dụng multi-agent của riêng mình.

## 🚀 Cách đóng góp dự án của bạn

### 1. Quy tắc đặt tên dự án

Định dạng tên thư mục dự án: `{Tên người dùng GitHub}-{Tên dự án}`

Ví dụ:
- `jjyaoao-CodeReviewAgent`
- `zhangsan-StudyBuddy`
- `lisi-DataAnalyst`

### 2. Yêu cầu về cấu trúc dự án

Mỗi dự án tối thiểu cần bao gồm:

```
tenNguoiDung-TenDuAn/
├── README.md              # Tài liệu mô tả dự án (bắt buộc)
├── requirements.txt       # Danh sách dependency Python (bắt buộc)
├── main.ipynb            # Jupyter Notebook chính (bắt buộc)
└── ...                   # Các file khác (tùy chọn)
```

### 3. Yêu cầu về README

README.md cần bao gồm các nội dung sau:

- Giới thiệu dự án
- Chức năng cốt lõi
- Technology stack
- Bắt đầu nhanh (cài đặt, cấu hình, chạy)
- Ví dụ sử dụng
- Thông tin tác giả

Template README chi tiết vui lòng tham khảo: [Template dự án](./EXAMPLE-ProjectTemplate/README_vi.md)

### 4. Quy trình gửi bài

1. Fork repository Hello-Agents
2. Tạo thư mục dự án của bạn trong thư mục `Co-creation-projects`
3. Hoàn thành phát triển dự án và viết tài liệu
4. Gửi Pull Request

Hướng dẫn gửi bài chi tiết vui lòng tham khảo: [Chương 16 Đồ án tốt nghiệp](../docs/chapter16/第十六章%20毕业设计_vi.md)
